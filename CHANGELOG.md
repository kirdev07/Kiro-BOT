# История изменений Kiro Bot

## 3.0 — финальная версия (октябрь 2026)

> Kiro Bot теперь целиком для Telegram. Если у вас был бот VK — после обновления добавьте бота Telegram (токен от @BotFather).

- **ИИ видит разговор:** последние реплики, включая ответы базы («столица Франции» → «а какое там население?»).
- **ИИ точнее базы там, где база не уверена:** случайные совпадения по одному слову уступают ИИ; если ИИ не ответил — бот берёт ответ базы, а не запасную фразу.
- **Бесплатные тарифы ИИ (Groq и др.):** запрос укладывается в лимит токенов, при отказе «Request too large» бот сам повторяет запрос меньше.
- **Поиск точнее:** «что такое фотосинтез» больше не проигрывает общему «объясни»; слова «там», «тут», «это» не считаются смыслом вопроса.
- **Штатная база:** убраны ответы, в которых бот сам грубил («нет», «ты лох» и др.); добавлен ответ на `/start`. Ваша база в `kirdev_base` не меняется.
- **Разговорный движок:** сообщение проходит цепочку обработчиков: ответы базы с учётом контекста → память → «а ты?» → точные ответы и команды → функции → короткие продолжения → реакции → поиск по смыслу → ИИ → запасной ответ. Ваша база по-прежнему главнее.
- **История диалога:** бот помнит 20 последних реплик отдельно для каждого собеседника в каждом чате (30 минут).
- **Короткие продолжения:** «а ты?» — ответ на тот же вопрос про бота; «да», «нет», «почему?», «серьёзно?», «ясно», «и что?» — с учётом только что сказанного.
- **Реакции:** на похвалу и ругань — вариативные ответы, без повторов подряд.
- **Функции:** «чай или кофе?», «инфа что…», «когда я…», время, дата, калькулятор, «рандом 1 100», «брось кубик».
- **Несколько вопросов в одном сообщении:** ответ на главный и, если коротко, на второй; приветствие — второстепенно.
- **Память имени:** «меня зовут Кирилл» → «как меня зовут?»; «забудь меня» — забыть.
- **Без повторов:** один и тот же ответ не звучит 5 ходов / 10 минут, пока есть другие варианты.
- **Журнал «Не знаю ответа»:** похожие вопросы объединяются, мусор (ссылки, «аааа», 1–2 символа) не пишется.
- **Отладка мозга:** переключатель в настройках — в «Логах» видно, почему бот ответил так.
- **Новая главная:** статус и запуск одной кнопкой, счётчики «Обработано / Отвечено» и время работы за сеанс (сбрасываются при каждом запуске), ИИ, характер, журнал «Не знаю», последние 5 сообщений; добавление, изменение и удаление бота прямо с главной.
- **Нижняя панель** вместо бокового меню: Главная, База, ИИ, Логи, Настройки. Вкладка «Боты» и кнопка «Включить / выключить» убраны — бот один. Чёрный список — в Настройках, «Связь с нами» — в меню ⋮.
- **Опечатки в одном слове** («превет», «спосибо») теперь находятся и на большой базе (раньше — только если рядом было правильное слово).
- **Политика конфиденциальности** — отдельный пункт в меню ⋮; **сайт для связи** [kirdev-studio.vercel.app](https://kirdev-studio.vercel.app/) — в меню и в окнах «О боте» и «Политика».
- **Только Telegram:** поддержка VK убрана целиком — ядро VK, загрузка фото в VK, поиск по ссылке VK в чёрном списке, настройка «отмечать прочитанным», выбор платформы. Боты VK из прошлых версий не загружаются — добавьте бота Telegram. Коды вложений VK из старых баз (`photo-1_2`) превращаются в ссылки и не теряются.
- **Жесты:** смахивание влево / вправо переключает вкладки (с анимацией), во вложенных экранах смахивание вправо — «назад»; в чёрном списке смахнуть человека — убрать (с кнопкой «Вернуть»); предиктивный жест «назад» на Android 13+.
- **Настройки по разделам:** Разговор, Беседы, Защита, Обучение и управление, Для разработчика — каждый открывается отдельно, «назад» возвращает к списку.
- **Ответ с цитатой** в VK — только в беседах, в личке обычным сообщением (как в Telegram).
- **Характер фраз:** «Обычный», «Тёплый», «Дерзкий», «Вежливый» — выбор в настройках, ответы вашей базы не меняются.
- Все фразы — в редактируемых файлах `kirdev_base/conversation*.txt`.

## 2.20 — бета-тест (сентябрь 2026)

> Версия проходит бета-тест. Бот работает, но возможны мелкие ошибки — пишите о них в канал.

### Главное
- **Новое имя:** «Kiro Bot VK» → **Kiro Bot**, версия 2.20.
- **Telegram:** при добавлении бота выбирается платформа — VK или Telegram.
- **Один бот вместо пяти:** приложение управляет одним ботом — проще настройка, меньше расход батареи.
- **ИИ-помощник:** если в базе нет ответа, отвечает нейросеть по вашему ключу.

### 🤖 ИИ-помощник (новый раздел в меню)
- Сервисы: **Claude** (Anthropic), **Gemini** (Google), **YandexGPT** и **любой OpenAI-совместимый API** — OpenAI, OpenRouter, DeepSeek, Groq, Grok (xAI), Mistral, а также локальные Ollama и LM Studio (без ключа).
- ИИ отвечает **только когда в базе нет ответа** — ваша база всегда главнее.
- Список моделей загружается сам: нажмите на поле «Модель» — появятся модели, доступные по вашему ключу.
- Настройки: характер бота, длина ответа, дневной лимит запросов (счётчик за сегодня), ответы в беседах вкл/выкл.
- Кнопка «Проверить» — проверка ключа и модели одним нажатием.
- Бот помнит 3 последних обмена репликами с каждым собеседником.
- Рассуждения «думающих» моделей (DeepSeek-R1, gpt-oss и др.) и Markdown вырезаются из ответа.
- Понятные ошибки: неверный ключ, кончились деньги, неверный адрес, адрес без https.

### 📓 Журнал «Не знаю ответа»
- Бот записывает вопросы, на которые не нашёл ответа, — с числом повторов.
- Если ответил ИИ, рядом видна его подсказка 🤖 — её можно добавить в базу одним нажатием.
- Журнал **можно выключить** в настройках.

### 💬 Обучение прямо из чата (для владельца)
- `!запомни вопрос = ответ` — добавить ответ в базу.
- `!забудь вопрос` — удалить.
- `!незнаю` — последние вопросы без ответа.
- `!команды` / `!помощь` — список команд; `!id` — узнать свой ID.
- Команды работают с большой буквы и с «ё».

### 🧠 Умный поиск
- Понимает длинные сообщения: разбирает их по фразам, приветствие не перебивает суть.
- Формы слов («работе» = «работа»), опечатки, «ё» = «е», сленг.
- Редкие слова важнее частых, служебные слова не мешают.
- **База синонимов** `kirdev_base/synonyms.txt` — дополняется вручную.

### 🖼 Картинки и видео
- Картинки и GIF с сайтов **скачиваются и приходят в чат картинкой**.
- Видео (YouTube, TikTok и др.) отправляются **ссылкой**.
- Поддержка **Pinterest**: фото по ссылке pin.it / pinterest приходит картинкой.

### ⚡ Скорость и удобство
- «Печатает…» появляется сразу, пока бот готовит ответ (особенно заметно с ИИ).
- Ключи и токены расшифровываются один раз и кэшируются.
- Настройки ИИ сохраняются без нагрузки на каждое нажатие клавиши.

### 🔒 Безопасность
- Токен бота и ключи ИИ хранятся **зашифрованными** (Android Keystore).
- Соединения только по HTTPS (http — только для локальных моделей на телефоне).
- Обновлены описание в приложении и политика конфиденциальности (как данные уходят в ИИ-сервис).

### 🐞 Исправлено
- Двойные ответы на одно сообщение.
- Зависание при неверном токене.
- Переписка бота с другими ботами.
- Команды с большой буквы («!Запомни») теряли текст.
- Пустые ответы от думающих моделей ИИ.
- Удалён старый неиспользуемый код, десятки мелких ошибок.

### Для разработчика
- 128 автотестов, все проходят.
- Релиз собирается `build_release.bat` → `KiroBot-2.20.apk` (≈7–8 МБ), подпись своим ключом.
